# Dreamy-Canvas
A dreamy and creative online art studio where colors, imagination, and emotions come together. 🎨✨ Explore beautiful paintings, discover inspiring artwork, and experience a little piece of creativity on every canvas. 🌸🖌️
## 🌸 About

**Dreamy Canvas** is an online art gallery created to showcase beautiful paintings and artwork in an elegant, aesthetic environment. Visitors can explore artwork, view painting details, place orders, and send messages through the contact form.

## ✨ Features

* 🎨 Beautiful artwork gallery
* 🖼️ Painting details and descriptions
* 🛒 Artwork purchase system
* 👤 Customer information management
* 📦 Order management
* 💌 Contact and messaging system
* 🔐 Admin functionality
* 📱 Responsive design
* 🌐 GitHub Pages deployment

## 💻 Technologies

* HTML5
* CSS3
* JavaScript
* Oracle Database
* Oracle APEX
* ORDS REST APIs
* GitHub Pages

## 🌷 Project

Dreamy Canvas combines art and technology to create a beautiful online space where visitors can discover, appreciate, and purchase artwork.
